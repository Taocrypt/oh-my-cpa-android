功能Features

控制台是 oh-my-cpa 本身；外壳补上手机上真正需要的原生能力。The console is oh-my-cpa itself; the shell adds what a phone actually needs.

首次启动自动部署Set up on first launch

从 GitHub Releases 下载官方 linux arm64 二进制，固定 SHA-256 校验，断点续传；可设下载镜像。Downloads the official linux arm64 binaries from GitHub Releases with pinned SHA-256 checks and resume; optional mirror.

后台常驻Stays running

前台服务托管两个进程，异常自动退避重启；支持忽略电池优化和开机自启。A foreground service supervises both processes with back-off restarts; battery exemption and start on boot.

Go DNS 兼容 + 自动登录DNS fix + auto-login

内置 DNS 代理，解决 Go 程序在 Android 上无法解析域名；管理密钥自动生成并填入。A built-in DNS proxy lets Go resolve names on Android; the management key is generated and filled in for you.

原生面板Native panel

可拖动的状态按钮，点开从右侧滑入的面板，配色实时跟随控制台主题。A draggable status button opens a right-hand panel that follows the console's live theme.

悬浮窗 · 气泡 · 磁贴Float window · bubble · tile

控制台小窗悬浮在其他应用之上，可缩放、调透明度、收成贴边气泡；快捷设置磁贴一键打开。Keep the console floating over other apps, resize it, fade it, tuck it into an edge bubble; Quick Settings tile.

局域网 & 远程访问LAN & remote access

一键监听 0.0.0.0（可选 mDNS）；Cloudflare Quick Tunnel 或 Tailscale 从任何地方访问。One switch to listen on 0.0.0.0 (optional mDNS); reach it anywhere via Cloudflare quick tunnel or Tailscale.

插件模式Plugin mode

跟随控制台「启用插件系统」：自动换用 CPA 插件版，经内置 Termux glibc 加载器运行；插件页自动获得管理密钥。Follows the console's plugin switch: runs CPA's glibc plugin build via a bundled Termux glibc loader; plugin pages get the key.

更新与空间管理Updates & storage

组件更新可回滚，外壳从 Releases 自更新并在通知栏显示进度；空间管理清理旧版本与日志。Component updates with rollback, shell self-update from Releases with notification progress, and a storage manager.

日志与诊断Logs & diagnostics

分标签查看各进程与崩溃日志，分享时自动脱敏密钥，一键导出诊断包。Per-process and crash logs, key-redacted sharing, and a one-tap diagnostics bundle.

工作原理How it works

两个上游程序原样运行在手机上，外壳只负责托管、连接与展示。Both upstream programs run unmodified on the phone; the shell supervises, connects and displays them.

安装Install

需要 Android 10（API 29）或更高的 arm64 设备。Requires an arm64 device on Android 10 (API 29) or later.

  1. 下载Download

    在 Releases 下载最新的 oh-my-cpa-<版本>.apk。Get the latest oh-my-cpa-<version>.apk from Releases.

  2. 安装Install

    允许浏览器或文件管理器「安装未知来源应用」，然后安装。Allow your browser or file manager to install unknown apps, then install it.

  3. 首次启动First launch

    等待下载并校验 CPA 与 oh-my-cpa；访问 GitHub 慢时打开「使用下载镜像」。Wait while CPA and oh-my-cpa download and verify; turn on the download mirror if GitHub is slow.

  4. 保持运行Keep it running

    允许通知；在面板 → 应用设置中「忽略电池优化」，必要时开启开机自启。Allow notifications; in Panel → App settings, exempt the app from battery optimisation and optionally start on boot.

  5. 开始使用Use it

    在控制台添加账号或 API Key，客户端 Base URL 填 http://127.0.0.1:8317/v1（局域网使用手机 IP）。Add accounts or API keys in the console and point clients at http://127.0.0.1:8317/v1 (or the phone's IP on your LAN).

FAQ

为什么首次启动还要下载？Why does it download things on first launch?

CPA 与 oh-my-cpa 二进制直接来自上游官方 Releases（版本固定、SHA-256 校验），APK 只包含外壳，因此体积小，上游更新也不必等外壳发版。下载失败可打开镜像后重试。The CPA and oh-my-cpa binaries come straight from the official upstream Releases (pinned versions, SHA-256 checked). The APK is only the shell, so it stays small and upstream updates don't wait for a new shell release. If a download fails, enable the mirror and retry.

需要哪些权限？What permissions does it need?

网络（本地服务与下载）、前台服务与通知（后台常驻与状态）、唤醒锁与忽略电池优化（可选）、开机启动（可选，默认关闭）、悬浮窗（仅在你使用悬浮窗时）、本地网络（局域网与 mDNS）、安装未知应用（仅用于外壳自更新）。应用不含任何统计或追踪 SDK。Network (local services and downloads), foreground service and notifications (staying alive, status), wake lock and battery exemption (optional), boot start (optional, off by default), draw over apps (only for the floating window), local network (LAN and mDNS), and install unknown apps (only for shell self-update). There are no analytics or tracking SDKs.

熄屏后 API 不通 / 服务被杀？The API stops when the screen is off?

在面板 → 应用设置中「忽略电池优化」。部分国产系统还需在系统设置里允许自启动与后台运行，并在多任务界面锁定应用。Exempt the app from battery optimisation in Panel → App settings. Some vendor ROMs also need auto-start / background permission in system settings and the app locked in recents.

数据存在哪里？Where is my data stored?

凭据、配置与数据库都在应用私有目录，不会被上传。开启局域网或远程访问前，请为 CPA 设置 API Key，并只在可信网络中使用。Credentials, config and databases stay in the app's private storage and are never uploaded. Before enabling LAN or remote access, set API keys in CPA and use trusted networks only.

这是官方应用吗？Is this an official app?

不是。Oh My CPA 是社区项目，与 CLIProxyAPI 和 oh-my-cpa 的作者没有从属关系。外壳的问题请在本仓库反馈。No. Oh My CPA is a community project and is not affiliated with the CLIProxyAPI or oh-my-cpa authors. Please report shell issues in this repository.
